## Français

Twitch Live Alert 0.2.0 surveille une catégorie Twitch dans la langue de votre choix sous Windows 10 ou 11 x64. La première version publique inclut la fenêtre de bureau, une icône dans la zone de notification et un tableau de bord accessible dans votre navigateur local.

- Recherchez une catégorie au clavier ou à la souris. Suivez une langue ou toutes les langues et consultez l’audience et l’heure de début des directs.
- Recevez une notification Windows lorsqu’une chaîne passe en direct et retrouvez-la dans le journal local après redémarrage.
- Configurez votre propre application Twitch. Windows protège les identifiants avec DPAPI pour votre compte. Les réglages et le journal de Bloodborne FR Live peuvent être repris. [Guide de migration pour cette version](https://github.com/LINDECKER-Charles/twitch-live-alert/blob/v0.2.0/docs/MIGRATION.md)

[Télécharger l’installateur Windows x64](https://github.com/LINDECKER-Charles/twitch-live-alert/releases/download/v0.2.0/Twitch-Live-Alert_0.2.0_x64-setup.exe). Cet installateur est non signé. Lancez-le, ouvrez **Twitch Live Alert** depuis le menu Démarrer et choisissez **Connexion Twitch**. WebView2 est téléchargé si nécessaire.

## English

Twitch Live Alert 0.2.0 monitors one Twitch category in your chosen broadcast language on Windows 10 or 11 x64. This first public release includes a desktop window, a notification-area icon and a dashboard you can open in your local browser.

- Search for a category with the keyboard or mouse, select one language or all languages, and see live viewer counts and stream start times.
- Get a Windows notification when a channel goes live. Search the local alert history after restarting the application.
- Connect your own Twitch application. Windows protects its credentials with DPAPI for your account. Existing Bloodborne FR Live users can carry over their settings and history.

[Download the Windows x64 installer](https://github.com/LINDECKER-Charles/twitch-live-alert/releases/download/v0.2.0/Twitch-Live-Alert_0.2.0_x64-setup.exe). This installer is unsigned. Run it, open **Twitch Live Alert** from the Start menu, then choose **Connexion Twitch**. The installer downloads WebView2 if required.
