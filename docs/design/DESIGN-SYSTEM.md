# Design system

Le thème sombre s’appuie sur les jetons de [web/style.css](../../web/style.css). Les surfaces encre et bordeaux structurent la page. Le laiton marque les actions principales, les liens et le focus. Les titres utilisent Georgia et les commandes Segoe UI. Les polices de secours sont déclarées dans les jetons.

La feuille unique regroupe les jetons, la base, les contrôles et les adaptations de largeur. Le texte rend l’état compréhensible indépendamment de la couleur. Le réglage système de mouvement réduit retire la transition des boutons.

La [planche](PLANCHE.md) situe les spécimens dans la page servie par l’application locale. Le thème initial fonctionne avec les ressources système.
